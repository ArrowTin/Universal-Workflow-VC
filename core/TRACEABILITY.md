# EXECUTION TRACEABILITY

Initialize before coding:

- `docs/TASK-PLAN.md`
- `docs/PHASE-LOG.md`
- `docs/TASK-LOG.md`

Every task should map to a commit. Material error fixes should use separate commits. Each completed phase should be pushed to the project remote when access permits.

Maintain:

```text
Requirement → Phase → Task → Agent → Skill → Model → Artifact → Test → Commit → Phase Push
```

Record failures or unavailable Git operations rather than fabricating completion.
