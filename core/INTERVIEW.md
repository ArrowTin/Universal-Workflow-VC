# INTERVIEW ENGINE

The interview is progressive, conditional and stateful.

## Language
- The interview must use Bahasa Indonesia by default.
- Technical and domain terms should remain in their original language when appropriate, e.g. API database, authentication, authorization, architecture, deployment, testing.
- The developer may choose another language or provide custom input at any time.

## Rules

- Never ask for information already known.
- Ask only questions that can change a decision.
- Group related decisions.
- Offer defaults.
- Allow custom input.
- Summarize periodically.
- Surface contradictions immediately.
- Stop interviewing when the information is sufficient for safe planning.

## Decision protocol

```text
Unknown
→ Ask
→ Record
→ Evaluate downstream impact
→ Ask conditional follow-up if necessary
→ Confirm material decision
```

## Completion criteria

The interview is complete when the project has enough information to produce:

- scope;
- users/roles;
- prioritized features;
- architecture;
- technology strategy;
- environment strategy;
- test strategy;
- security posture;
- deployment strategy;
- constraints;
- assumptions;
- risks.
