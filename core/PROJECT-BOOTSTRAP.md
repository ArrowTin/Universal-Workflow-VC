# PROJECT BOOTSTRAP

Layer 1 is always separate from the project output repository.

Before generating project documentation for a new project:

1. identify the workflow repository;
2. ask for the Project Output Repository;
3. verify they are different repositories;
4. persist interview state;
5. after approval generate `AGENTS.md` and `docs/`;
6. keep Layer 2 and Layer 3 in the same project repository.

Layer 2 must include a derived copy of the general operating rules needed to execute the project without requiring the Layer 1 repository at runtime.
