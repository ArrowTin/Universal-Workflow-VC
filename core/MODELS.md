# MODEL ROUTING

The workflow is provider/model agnostic.

## Routing signals

- complexity;
- reasoning;
- context size;
- privacy;
- risk;
- latency;
- cost;
- credits;
- historical performance.

## Policy

Use the least expensive model that is sufficient for the task.

Use stronger models when the expected value of higher quality justifies the additional cost/risk reduction.

A model change must preserve project state through artifacts and checkpoints.
